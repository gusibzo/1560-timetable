# youtube-summarizer

## 사용법

| 입력 | 동작 |
|---|---|
| `/youtube-summarizer` | `config.json`에 고정된 URL을 요약 |
| `/youtube-summarizer <URL>` | 그 URL만 이번에 요약 (고정 URL은 그대로 둠) |
| `/youtube-summarizer 고정 <URL>` (또는 `set <URL>`) | URL을 고정 저장한 뒤 요약 |
| `/youtube-summarizer 고정확인` | 현재 고정 URL만 보여줌 |

스크립트 경로: `.claude/skills/youtube-summarizer/scripts/yt.py` (이 파일 기준 상대 경로 `scripts/yt.py`)

## 절차

1. **URL 결정**
   - 인자에 `고정`/`set` + URL이 있으면: `python3 scripts/yt.py set <URL>` 실행 후 그 URL 사용.
   - 인자에 URL만 있으면: 그 URL 사용.
   - 인자가 없으면: `python3 scripts/yt.py get` 으로 고정 URL 사용. 없으면 사용자에게 URL을 요청하고 멈춘다.
2. **자막 수집**: `pip install -q youtube-transcript-api` (없을 때만) 후 `python3 scripts/yt.py fetch <URL>`.
   - 출력은 `[mm:ss] 문장` 형식이다. 이 타임스탬프만 근거로 쓴다. 타임스탬프를 지어내지 않는다.
   - 실패하면(자막 없음, 네트워크 차단) 오류 메시지를 그대로 알리고, 사용자에게 자막 텍스트를 붙여넣어 달라고 요청한다. 영상 내용을 추측해서 요약하지 않는다.
3. **요약 작성** — 아래 출력 형식을 따른다.

## 출력 형식

```
## 📺 <영상 제목 또는 video_id>
🔗 <URL>

### 한 줄 요약
...

### ⏱ 타임스탬프 요약
- [00:00] 구간 주제 — 핵심 내용 1~2문장
- [03:15] ...
(주제가 바뀌는 지점마다 1개, 10분 영상 기준 5~10개)

### 🚩 과장된 투자 주장
| 시간 | 발언(원문 요지) | 유형 | 왜 문제인가 / 확인할 점 |
|---|---|---|---|
| [12:40] | "이 종목 무조건 3배 간다" | 수익 보장 | 근거 없는 확정 표현, 목표가 산출 근거 제시 없음 |

(없으면 "과장된 투자 주장 없음"이라고 쓴다)

### ✅ 검증 가능한 사실 주장
- [mm:ss] 수치·실적·날짜 등 확인 가능한 주장 — 확인 출처 제안(DART 공시, 실적 발표 등)

### 💡 시청자 체크포인트
- 실행 전에 확인할 것 2~4개
```

## 과장된 투자 주장 판별 기준

다음 중 하나라도 해당하면 🚩 표에 넣는다:

- **수익 보장/확정**: "무조건", "100%", "확정", "절대 안 떨어진다", "원금 보장"
- **비현실적 수익률**: 단기간 몇 배·수십 % 수익을 쉽게 말함
- **긴급성 조장**: "지금 안 사면 늦는다", "오늘이 마지막 기회", "곧 폭등"
- **근거 없는 목표가**: 산출 근거 없이 구체적 가격·날짜 예언
- **위험 축소/누락**: 하락·손실 가능성을 언급하지 않거나 무시
- **체리피킹**: 성공 사례만 제시, 과거 수익률을 미래 보장처럼 표현
- **이해상충 미공개**: 리딩방·유료회원·특정 상품 유도, 본인 보유 여부 미공개
- **권위 남용**: "내부 정보", "세력", "기관이 몰래 산다" 등 검증 불가 주장

원칙:
- 발언은 자막에 실제로 있는 내용만 인용하고 반드시 타임스탬프를 붙인다.
- 판정은 "과장 가능성"으로 표현하고, 사실 여부를 단정하지 않는다.
- 요약 끝에 "투자 판단은 본인 책임이며, 이 요약은 투자 권유가 아닙니다." 한 줄을 붙인다.
